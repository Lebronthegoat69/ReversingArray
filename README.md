# Array, Stack, and Queue Reversal
## Project Description
This Java program asks the user to enter a number of integer values and stores those values in three different collections: an integer array, a Stack, and a Queue. The program displays the original values, reverses each collection, and displays the reversed values.

The array is reversed by swapping elements inside the original array. The Stack and Queue are also reversed so that the values appear in reverse order.
## Concepts Used
* Java arrays
* Stack<Integer>
* Queue<Integer>
* Scanner for user input
* Loops
* Swapping array elements
* Reversing collections
* Methods for displaying collection values
## How to Run the Program
1. Open the project in IntelliJ IDEA.
2. Open `ReversingArray.java`.
3. Run the program using the green Run button.
4. Enter the number of integer values you want to use.
5. Enter each integer when prompted.
6. Review the original and reversed values displayed in the console.
